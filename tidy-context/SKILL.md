# 指示ファイルの片付け

対象のプロジェクトの CLAUDE.md、AGENTS.md、`.claude/rules/`、各フォルダの CLAUDE.md、`.claude/skills/` を読み、指示を1つずつ次の2軸で分ける。

- **ルール**（振る舞いの指示）か、**情報源**（そのプロジェクトや人についての事実）か
- **いつでも要る**か、**特定のフォルダ・作業のときだけ要る**か

置き場所:

| | いつでも要る | 特定のフォルダのときだけ | フォルダに紐づかない作業のときだけ |
| --- | --- | --- | --- |
| ルール | `.claude/rules/`（`paths` なし） | `.claude/rules/`（`paths` で絞る） | その作業のスキル |
| 情報源 | CLAUDE.md | そのフォルダの CLAUDE.md | その作業のスキル |

あわせて次も指摘する。

- 機械的に確かめられるルール → hook・lint・テストにする候補（CLAUDE.md は強制ではない）
- 今のモデルなら書かなくても守れるルール → 消す候補。情報源はモデルが賢くなっても消さない
- 同じことが2か所以上にある → どちらを正にするか

## 出力

表で返す: 指示（短く）・今の場所・分類（ルール/情報源 × いつでも/フォルダ/作業）・移す先・理由。最後に、移したあとの CLAUDE.md のおおよその行数を書く。

ファイルは変えない。承認されたら移す。`~/.claude` の下のファイルは全プロジェクトに効くので、提案するときはそう明記する。AGENTS.md は Codex が `.claude/rules/` やスキルを読まないので、移した先を読むよう案内する形にする。
